# 🍬 My Candy — Interactive Monthsary Love Story

A personal, scroll-based love story website made for a 3rd monthsary.

## ✨ Features
- Scroll-triggered story sections with smooth reveal animations
- Animated relationship timeline
- Typing love letter effect (with realistic speed variation)
- Floating ambient hearts (canvas-based)
- Click-anywhere hearts interaction
- Mobile-friendly & responsive
- No frameworks — pure HTML, CSS, JS

## 🚀 How to Run
1. Download or clone this repository
2. Open `index.html` in any browser
3. Scroll slowly and enjoy ❤️

## 💌 How to Customize
- **Letter**: Edit the `message` variable in `script.js`
- **Timeline**: Edit the `.tl-item` entries in `index.html`
- **Colors**: Change CSS variables at the top of `style.css`
- **Name**: Search and replace "My Candy" in `index.html`

## 🌐 Deploy
Works instantly on:
- **GitHub Pages** — push to a repo, enable Pages in Settings
- **Netlify** — drag and drop the folder
- **Vercel** — import from GitHub

No build step needed.
